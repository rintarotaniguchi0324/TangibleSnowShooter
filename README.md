# TangibleSnowShooter

## 概要 (Overview)
**TangibleSnowShooter** は、現実空間のテーブル上で自作の駒（タンジブルUI）を動かして遊ぶ、新感覚の2人用対戦シューティングゲームです。

OpenCVのArUcoマーカー認識を活用し、現実の駒の位置や角度とゲーム内のオブジェクトをリアルタイムに連動させます。各プレイヤーは「タンク駒」と「シールド駒」を操作し、雪玉をぶつけ合って対戦します。

## 準備するもの (Requirements)
本ゲームを遊ぶためには、以下のハードウェアと工作材料が必要です。

- **ゲーミングPC** (Unityアプリケーションが快適に動作するスペック)
- **USBカメラ × 2台**
- マーカーを印刷した紙 × **2枚** (※別ファイル [TSSMarkers.pdf](TSSMarkers.pdf) を印刷してください)
- **テーブル動作用の材料**
  - 段ボール
  - アクリル板
  - LED照明 (アクリル板の上から下向きに設置し、カメラの認識精度を上げるため)
- **駒用の材料**
  - 厚紙 (持ちやすい形に加工します)

## 準備手順 (Setup)

### 1. テーブルと駒の作成
プレイヤー1人につき、テーブル1台と駒2種（タンク、シールド）が必要です。合計でテーブル2台、タンク駒2個、シールド駒2個を作成します。

作成の詳細は別ファイルの[ハードウェア作成手順.pdf](ハードウェア作成手順.pdf)をご参照ください。
※テーブルの構造：段ボールの上にアクリル板を載せ、段ボール底面にUSBカメラを上向きに設置します。

### 2. 環境構築・起動

1. 本リポジトリをクローン、またはビルド済みの実行ファイルをダウンロードします。
2. PCに2台のUSBカメラを接続します。
3. アプリケーション（またはUnityエディタのPlayボタン）を起動します。

## 遊び方 (How to Play)

### 1. 初期配置
作成したテーブルを2台並べます。それぞれのテーブルのアクリル板の上に、タンク駒とシールド駒を1つずつ配置します。

### 2. カメラのセットアップ
ゲーム画面上に「カメラデバイス選択」UIが表示されます。
テーブルの底面に設置された2台のUSBカメラをそれぞれ選択してください。選択するとプレビュー画面が表示されるので、アクリル板の裏側（駒の底面に貼られたArUcoマーカー）が鮮明に映っていることを確認します。

### 3. ゲーム開始
カメラの映像が正常に認識されていることを確認したら、画面上の **[Start]** ボタンをクリックします。
3カウントのダウン後、ゲームが開始されます。

### 4. 操作方法とルール
- **移動と回転**: 現実のテーブル上で駒を動かす・回すことで、ゲーム画面上のタンクとシールドの位置・角度（横回転）を制御します。
- **攻撃**: タンクはゲーム中、常に前方に「雪玉」を発射し続けます。
- **防御**: シールド駒を使って相手の雪玉を防ぐことができます。ただし、シールドは**自分の発射した雪玉も防いでしまう**ため、配置には注意が必要です。
- **勝利条件**: 相手のタンクに雪玉を命中させるとHPが減少します。先に相手のHPを `0` にしたプレイヤーの勝利となります。
